## 最有价值的发现：426 页移动端菜单打不开
- 现象链：`agri-ui.css:1809` 在移动端 `.ag-nav{display:none}`，而工具页/根级页**没有引 `agri-ui.js`** → `data-ag-menu-toggle` 按钮无人绑事件 → 菜单永远打不开。占全站 50%。
- 排查顺序很关键：**先确认 DOM 钩子齐不齐**（全站 846 页都有 `data-ag-menu-toggle` + `#agMobileNav`，说明当初迁移是照搬模板，只是漏引脚本）→ 再看 JS 选择器（`agri-ui.js` 用 `[data-ag-menu-toggle]`，与 HTML 对得上）→ 最后看 CSS（`.ag-mobile-nav[data-open="true"]{display:block}`）。
- 结论：只需补 `<script src="/assets/js/agri-ui.js?v=2" defer>`。`common.js` 里根本没有 menu-toggle 逻辑（它只管 dark-mode / favorite / history / lang-btn）。
