### 踩坑（写这类正则补丁时反复遇到）
- **5 位码点必须写 `\U0001F000`**：写成 `\u1F000` 会被 Python 拆成 `\u1F00` + 字符 `0`，正则里凭空多出 U+0030–U+1FAF 的巨大区间，把整个 ASCII 表判成 emoji
- **宿主正则不能写死属性顺序**：`<a href="/" class="retry-btn" …>` —— 写 `<a class="retry-btn"` 直接漏
- **宿主正则要放 `[^>]*`**：`<div class="amazon-product-icon-fallback" style="display:none;">` 上的 style 属性会让 `(<div class="X">)` 失配
- **ZWJ 组合 emoji 要整串匹配**：🧑‍🌾 = U+1F9D1 + ZWJ + U+1F33E，只匹配前半截会在中间留一个零宽连接符
- **收尾清 VS16**：`🏚️ ⚙️ 🌡️` 的变体选择符在 base emoji 被替换后变成孤儿
- **XML 校验会误报**：`data-ag-icon` 是 HTML 布尔属性（无值），`ET.fromstring` 不接受 —— 校验前先补成 `data-ag-icon="1"`

### 配套 CSS（agri-ui.css）
老样式表给这些容器设的是 `font-size`（给 emoji 用），SVG 用 1em 自然跟着走，只需补 ① 去基线间隙 ② 按底色定色。
**关键一处**：`.tool-card:hover .tool-icon-wrap` 会翻成深绿渐变底，图标必须同步反白，否则 hover 时「消失」。

### 顺手修的既有损坏

**修法只能是「每轮只补第一个违规点、重新扫」** —— depth 一旦居高不下，后面每个 `<p>` 都会被判成违规点，一次全补会补多。

### 1. 配色收敛（`_color_map.py` v3）

### 4. ⚠️ 本轮最容易漏的一处：兜底规则的 `:not([style])`

**顺手修掉一个存量可访问性问题**：首页 hero 用的是老类名 `.hero-section`（不是 `.ag-hero`），从没拿到 `--ag-c-text`，副标题被兜底刷成正文色 —— 绿底深字，对比度不合格。现在正常了。
